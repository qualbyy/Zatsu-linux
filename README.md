> Программа разрабатывалась на основе концепции одноимённой программы от **Марка Аддерли (Mark Adderley)**, адаптированная для дистрибутивов **Arch Linux / EndeavourOS** с окружением **KDE Plasma 6** (Wayland и X11).

Автономная среда глубокой концентрации и фокусировки внимания для Linux. При запуске приложение мягко изолирует рабочий процесс, заменяя стандартную оболочку `plasmashell` на минималистичное рабочее окружение с таймером сессий, виджетами KDE 6 Breeze, встроенным лаунчером и строгим контролем отвлекающих приложений.

## Особенности проекта

### 1. Архитектура рабочего пространства
* **Полноэкранная поверхность рабочего стола:** Поддерживает обои KDE или пользовательские изображения, свободное перемещение значков с привязкой к сетке и виджеты.
* **Интегрированная панель задач:** Закреплена внизу экрана, содержит трей, часы, регулятор громкости, переключатель раскладки, лаунчер и кнопки управления сессией.
* **Управление окнами и переключение фокуса:** Запущенные приложения отображаются на панели задач. Клик активирует существующее окно через D-Bus KWin, правый клик открывает контекстное меню (закрытие, закрепление на рабочем столе).
* **Безопасная изоляция Plasma Shell:** Во время сессии фокуса служба `plasma-plasmashell.service` временно маскируется и останавливается. При выходе из Zatsu Focus Plasma гарантированно размаскируется и восстанавливается в исходное состояние.

### 2. Таймеры и методики продуктивности
* **Режим Pomodoro:** Циклы 25 минут фокусировки и 5 минут отдыха. Во время перерыва блокировщик фоновых программ автоматически приостанавливается, а статусная панель окрашивается в зеленый цвет.
* **Таймер обратного отсчета:** Быстрые пресеты от 15 минут до 12 часов с реактивным индикатором прогресса и системными уведомлениями.
* **Плавающий мини-таймер (PiP, `Meta+T`):** Компактный перетаскиваемый оверлей всегда поверх всех окон с кнопками паузы/старта для работы с IDE и браузером.
* **Статистика продуктивности и серии дней:** Аналитика времени в фокусе, количество пройденных раундов Pomodoro, подсчет непрерывной серии дней (streak) и 7-дневная гистограмма (хранится в `~/.config/zatsu-focus/stats.json`).
* **Строгий режим (Strict Blocker):** Автоматическое завершение нежелательных процессов по белому списку разрешенных приложений.

### 3. Звуковое сопровождение и защита внимания
* **Фоновые звуковые пейзажи (Ambient Soundscapes):** Встроенные бесконечные петли без сторонних зависимостей (Дождь, Утренний лес, Уютный камин, Розовый шум, Бинауральные альфа-волны 10 Гц) с регулировкой громкости в медиаплеере.
* **Блокировщик отвлекающих веб-сайтов:** Интеллектуальное подавление вкладок и сайтов (YouTube, Reddit, VK, Twitter, Twitch и др.) через мониторинг активных окон и локальную блокировку.
* **Режим «Не беспокоить» (KDE Plasma DND):** Автоматическое подавление всплывающих уведомлений через интерфейсы D-Bus `org.freedesktop.Notifications.Inhibit` и `org.kde.NotificationManager` с полным восстановлением при выходе.
* **Быстрые мысли сессии (Scratchpad, `Meta+N`):** Всплывающий Markdown-блокнот для фиксации спонтанных мыслей и временных задач без переключения контекста (сохранение в `scratchpad.md`).

### 4. Рабочий стол и виджеты в стиле KDE 6 Breeze
* **Breeze Clock Widget:** Крупные полупрозрачные часы и дата, синхронизированные со статусом сессии.
* **Виджет «Фокус дня» (Todo List):** Интерактивный список ключевых задач с отметками выполнения, сохранением состояния и счетчиком прогресса.
* **Светлая тема иконок Breeze (`breeze-dark`):** Векторные монохромные пиктограммы высокой четкости (#fcfcfc), органично встроенные в темную цветовую палитру KDE.

### 5. Системная интеграция KDE Plasma
* **Quick Runner (`Meta+F`):** Быстрый поиск установленных программ, встроенный калькулятор с копированием ответа в буфер обмена по Enter и запуск консольных утилит через префикс `>` (например, `> btop`).
* **Менеджер буфера обмена (`Meta+V`):** Вызов нативного меню Klipper через D-Bus.
* **Управление звуком:** Регулятор громкости PipeWire / WirePlumber с поддержкой прокрутки колесиком мыши, Mute по клику колесиком и всплывающего слайдера.
* **Переключение раскладки:** Быстрое переключение языков ввода клавиатуры (EN / RU) по клику на индикатор или по горячим клавишам.

## Горячие клавиши

Все сочетания клавиш можно переназначить в меню Zatsu (вкладка **«Горячие клавиши»**), поддерживается интерактивная запись клавиш:

| Сочетание по умолчанию | Назначение |
|---|---|
| `Meta` (Super) / `Alt+F1` | Открыть / закрыть главное меню Zatsu |
| `Meta+F` / `Ctrl+Space` | Быстрый поиск и командная строка (Quick Runner) |
| `Meta+V` / `Ctrl+Alt+V` | История буфера обмена (KDE Klipper) |
| `Meta+N` / `Ctrl+Alt+N` | Быстрый блокнот мыслей сессии (Scratchpad) |
| `Meta+T` / `Ctrl+Alt+T` | Плавающий мини-таймер поверх всех окон (Picture-in-Picture) |
| `Alt+Shift` / `Ctrl+Shift` / `Meta+Space` | Переключение раскладки клавиатуры |
| `Meta+L` / `Ctrl+Alt+L` | Блокировка сеанса экрана |
| `Meta+S` | Включение / выключение строгого режима |
| `Meta+R` | Сброс таймера текущей сессии |
| `Esc` | Закрыть активные всплывающие меню и окна |

## Требования к системе

* **ОС:** Arch Linux / EndeavourOS (или другие дистрибутивы на базе Arch).
* **Окружение:** KDE Plasma 6 (сессии Wayland или X11).
* **Python:** 3.10 или новее.
* **Системные зависимости:**
  ```bash
  sudo pacman -S python-pyside6 python-psutil python-requests python-dbus libpulse
  ```

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/qualbyy/zatsu-focus.git
cd zatsu-focus
```

### 2. Системная интеграция (рекомендуется)
Для создания ярлыка в меню KDE, установки SVG-иконки и интеграции в поиск KRunner запустите установочный скрипт:
```bash
chmod +x install.sh uninstall.sh restore-plasma.sh
./install.sh
```
После этого приложение станет доступно в меню приложений KDE под названием **Zatsu Focus**.

### 3. Запуск вручную через терминал

* **Полноэкранный рабочий режим:**
  ```bash
  python3 main.py
  ```

* **Оконный режим (для разработки, тестирования и отладки):**
  ```bash
  python3 main.py --windowed --no-plasma-stop
  ```

* **Запуск с заданной длительностью сессии:**
  ```bash
  python3 main.py --duration 45
  ```

## Восстановление Plasma Shell

Приложение автоматически восстанавливает стандартный рабочий стол KDE Plasma при нажатии кнопки выхода или при получении сигналов завершения (SIGINT, SIGTERM).

Если процесс был принудительно убит извне (`kill -9`):
```bash
./restore-plasma.sh
```
Скрипт размаскирует службу `plasma-plasmashell.service`, запустит ее и вернет стандартный рабочий стол.

## Удаление интеграции

Для удаления ярлыка приложения и связанных системных файлов:
```bash
./uninstall.sh
```
