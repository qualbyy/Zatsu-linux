# Zatsu Focus для Linux (EndeavourOS / Arch Linux, KDE Plasma 6)

Автономное приложение для глубокой концентрации и фокусировки внимания. Программа разрабатывалась на основе одноимённой программы от Марка Аддерли (Mark Adderley), специально адаптированная для дистрибутивов **Arch Linux / EndeavourOS** с окружением **KDE Plasma 6** с поддержкой сессий **Wayland** и **X11**.

---

## Ключевые возможности и архитектура

### 1. Архитектура окон (Always On Top Panel + Desktop Layer)
- **Панель задач поверх всех окон (`Qt.WindowStaysOnTopHint`):**
  - Панель задач всегда находится поверх открытых программ (браузера, Dolphin, терминала, текстового редактора).
  - Поддерживает плавное раскрытие наверх при открытии меню, громкости, календаря или плеера, и мгновенно возвращается к высоте 48px при закрытии всплывающих окон.
- **Рабочий стол (`Qt.WindowStaysOnBottomHint`):**
  - Полноэкранная поверхность с системными или пользовательскими обоями, свободным размещением иконок и виджетами KDE 6.
  - Находится под окнами работающих приложений и не сворачивается при нажатии `Win+D`.
- **Защита от автозапуска Plasma (`systemctl mask`):**
  - При переходе в режим фокусировки служба `plasma-plasmashell.service` маскируется и аккуратно останавливается, предотвращая повторный самопроизвольный запуск Plasma в фоне.
  - При выходе из Zatsu Focus (`shellManager.exit_focus_mode()`) служба размаскируется и восстанавливается в исходное состояние.

---

### 2. Виджеты рабочего стола в стиле KDE Plasma 6
- **Большие часы (KDE 6 Breeze Clock Widget):**
  - Крупные полупрозрачные часы и дата в стиле Breeze.
  - Статусный бейдж сессии («Фокусировка активна» / «Отдых Pomodoro»).
- **Виджет «Фокус дня» (Todo List):**
  - Интерактивный список ключевых задач на сессию.
  - Чекбоксы выполнения с зачёркиванием, счётчик выполненных задач (`X/Y`), удаление задач и поле быстрого добавления (`+ Новая задача`).
  - Данные задач сохраняются в конфигурации пользователя.
  - Виджеты можно независимо включать и отключать во вкладке «Рабочий стол» меню Zatsu.

---

### 3. Режимы таймера: Обратный отсчёт и Pomodoro (25 / 5)
- **Техника Pomodoro:**
  - Автоматическое чередование циклов: 25 минут работы (глубокий фокус) и 5 минут отдыха (короткий перерыв).
  - Во время перерыва **строгий блокировщик автоматически приостанавливается**, позволяя расслабиться и открыть любые приложения.
  - По окончании перерыва отправляется системное уведомление и начинается новый раунд фокуса.
  - Визуальный индикатор в панели задач: зелёный бейдж `Отдых 04:59`.
- **Обычный таймер обратного отсчёта:**
  - Пресеты: 15 мин, 25 мин, 45 мин, 1 час, 2 часа, 4 часа, 8 часов, 12 часов с реактивной подсветкой выбранного значения.
  - Кнопка мгновенного перезапуска таймера.

---

### 4. Управление громкостью звука (PipeWire / WirePlumber)
- **Регулятор в панели задач:**
  - Динамическая иконка Breeze (`audio-volume-high`, `audio-volume-medium`, `audio-volume-low`, `audio-volume-muted`).
  - **Прокрутка колёсиком мыши** по иконке громкости увеличивает или уменьшает громкость на ±5%.
  - **Клик колёсиком (средней кнопкой):** мгновенное переключение Mute.
  - **Левый клик:** всплывающее меню громкости Breeze с ползунком и быстрыми пресетами (0%, 25%, 50%, 75%, 100%).

---

### 5. Выделенная кнопка блокировки экрана
- Значок `system-lock-screen` в системном трее панели задач.
- Мгновенная блокировка сессии через `loginctl lock-session` и D-Bus ScreenSaver.

---

### 6. Быстрый запуск и командная строка: Quick Runner (`Meta+F`)
- Всплывающее модальное окно по центру экрана (аналог KRunner / Spotlight).
- **Горячая клавиша:** **`Meta+F`** (а также `Ctrl+Space`).
- **Возможности:**
  - Мгновенный поиск и запуск любой из 120+ системных программ.
  - Встроенный калькулятор: ввод выражений вроде `(120+45)*2` с мгновенным выводом, по нажатию `Enter` результат копируется в буфер обмена.
  - Запуск терминальных команд: ввод с префиксом `>` (например, `> btop`, `> git status`) открывает команду в эмуляторе терминала.
  - Быстрые команды: `lock` (блокировка экрана), `strict` (переключение строгого режима), `exit` (выход из Zatsu), `timer 45` (установка таймера).
  - Навигация стрелками `↑` / `↓`, запуск по `Enter`, закрытие по `Esc`.

---

### 7. Системные горячие клавиши
| Сочетание | Действие |
|---|---|
| **`Meta`** (Super) / **`Alt+F1`** | Открыть / закрыть главное меню Zatsu |
| **`Meta+F`** / **`Ctrl+Space`** | Открыть Quick Runner (быстрый запуск, расчёт, терминал) |
| **`Meta+V`** / **`Ctrl+Alt+V`** | Открыть историю буфера обмена (KDE Klipper) |
| **`Alt+Shift`** / **`Ctrl+Shift`** / **`Meta+Space`** | Переключение раскладки клавиатуры |
| **`Meta+L`** / **`Ctrl+Alt+L`** | Блокировка экрана |
| **`Meta+S`** | Включение / выключение строгого режима |
| **`Meta+R`** | Сброс таймера текущей сессии |
| **`Esc`** | Закрыть активные всплывающие окна и поиск |

## Установка и интеграция в KDE Plasma 6

В репозиторий включены автоматические скрипты интеграции:

### 1. Установка в систему
```bash
cd ~/.gemini/antigravity/scratch/zatsu-focus
./install.sh
```
Скрипт:
- Устанавливает векторную SVG-иконку Breeze в `~/.local/share/icons/hicolor/scalable/apps/zatsu-focus.svg`.
- Создаёт ярлык `~/.local/share/applications/zatsu-focus.desktop`.
- Обновляет кэши меню KDE Plasma (`kbuildsycoca6`, `update-desktop-database`).
- Приложение сразу появляется в системном меню приложений и поиске KRunner!

### 2. Запуск вручную
```bash
# Стандартный запуск в полноэкранном режиме фокусировки:
python3 main.py

# Оконный режим (для тестирования и отладки):
python3 main.py --windowed --no-plasma-stop
```

### 3. Удаление интеграции
```bash
./uninstall.sh
```

## Экстренное восстановление Plasma Shell
Если сессия была принудительно завершена по `kill -9`:
```bash
./restore-plasma.sh
```
Скрипт автоматически размаскирует службу `plasma-plasmashell.service`, запустит её и восстановит привычный рабочий стол.
